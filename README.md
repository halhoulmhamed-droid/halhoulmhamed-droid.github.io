# Mhamed Halhoul — Portfolio

A dependency-free static portfolio for [Mhamed Halhoul](https://github.com/halhoulmhamed-droid), built for the canonical GitHub Pages address:

`https://halhoulmhamed-droid.github.io/`

## Pages

- Home
- About
- Projects
- Talk-to-Agent case file
- Hujja case file
- Custom 404 page

## Technology

- Semantic HTML5
- Modern CSS3
- Minimal vanilla JavaScript for the responsive navigation and footer year

There are no dependencies, package-manager files, build tools, analytics, cookies, forms, external fonts, or third-party runtime assets.

## Local preview

From the repository root, run any static HTTP server. With Python installed:

```text
py -m http.server 8000
```

Then visit `http://127.0.0.1:8000/`.
