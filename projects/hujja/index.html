Hujja · auditable rules as code

Pre-alpha software project for auditable Shariah stock-screening rules. Published DJIM contract, JSON Schema, fact model and validation tests; execution engine not yet implemented.

Problem

Stock-screening methodologies can disagree on financial thresholds, denominators, excluded activities and transition rules. Hujja explores how to make those differences inspectable, with one prospective verdict per standard and explicit links between each claim and its evidence.

Approach

A declarative YAML contract describes the DJIM methodology with a strict JSON Schema, independently versioned rule content and format, a normalized fact model, and claim-level provenance. Documentary support, source consistency and pending engineering decisions remain separate. Historical rules are recorded as non-operative; the two directions of compliance transitions are represented independently.

Documented contribution

Halhoul Mhamed’s published contribution is the pre-alpha rule contract and its accompanying schema, fact-model documentation and validation suite. These artifacts make assumptions and unresolved dependencies visible before implementing a loader or execution engine. The package metadata identifies him as the author.

Published artifacts

  • A versioned DJIM rule file, format version 2.0.0, with public evidence references and explicit open decisions.
  • A JSON Schema and validation tests covering reference integrity, documentary boundaries, operands and transition semantics.
  • A fact model distinguishing issuer data, caller-supplied market observations, external classifications and prior engine state.

No stock-verdict dataset, divergence matrix or screening benchmark is published at this revision. The README’s target API and future adapters describe planned work.

Limits and current status

Pre-alpha: the loader and execution engine are not implemented. The DJIM rule file remains unreviewed; a structural validation suite does not establish expert approval or financial accuracy.

Evaluation-period timing, sampling of market capitalization, external-classification interfaces and missing-input behavior remain unresolved. Market capitalization cannot be derived from EDGAR filings alone and requires caller-supplied observations. Stateful index replication cannot be implemented until its period semantics are resolved.

Hujja is an informational and educational project. It does not issue fatwas or provide investment advice.
